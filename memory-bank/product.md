# Product

## Контекст
- Продукт: `mymeet.ai` (цифровой двойник текущего продукта)
- Описание: AI-ассистент для онлайн-встреч, который фиксирует ключевые моменты и помогает быстро разобраться в содержании разговоров
- Референс: `https://mymeet.ai/ru/`

## Целевая аудитория
- Пользователи, которым нужно быстро понимать суть онлайн-встреч без полного переслушивания

## Ключевые сценарии
- Открыть экран всех встреч и получить обзор
- Использовать поиск для быстрого нахождения нужного разговора/темы
- Открыть интеграции для подключения внешних сервисов
- Управлять параметрами продукта на экране настроек

## Принцип роста
- Экранный подход: добавление по этапам, а не все сразу
- Стабильность: неизменные элементы интерфейса не пересобираются без отдельного решения
- Расширяемость: новые разделы добавляются так, чтобы не ломать уже сделанные экраны
