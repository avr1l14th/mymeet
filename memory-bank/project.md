# Project

## Контекст
- Рабочее название: цифровой двойник продукта `mymeet.ai`
- Продукт: AI-ассистент для онлайн-встреч
- Ценность: фиксирует ключевые моменты и помогает быстро разобраться в содержании разговоров

## Текущее состояние
- Подход: поэтапное добавление основных экранов
- Базовые направления экранов:
  - Поиск
  - Все встречи
  - Интеграции
  - Настройки
  - Дополнительные разделы будут добавляться по мере работы

## Неизменный каркас
- Боковое меню остается стабильным
- Добавление новых экранов не должно ломать уже собранные части
- Общая структура навигации должна быть предсказуемой при росте продукта

## Ограничения
- Масштабируемость важнее точечных визуальных правок
- Новые элементы добавляются модульно, без нарушения существующего поведения

## Следующие шаги
- Вести поэтапный план экранов в `tasks.md`
- Фиксировать неизменные части интерфейса и ключевые решения в `decisions.md`
